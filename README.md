# 駅レーダーサイト

駅メモ！非公式ファンツール

https://hinoharu.github.io/eki-radar/

機能紹介・使い方・計算の仕組み・更新履歴：https://hinoharu.github.io/eki-radar/guide/

## 概要

本ツールは、位置情報ゲーム「駅メモ！ - ステーションメモリーズ！-」（以下「本ゲーム」といいます。）のアイテム「レーダー」について、指定した駅が検知の対象となる地域を推定し、地図上に表示するウェブアプリケーションです。
